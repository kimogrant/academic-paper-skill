
### 7.1 Standard dissertation skeleton (adapt to handbook)

**Trigger:** "dissertation structure", "thesis outline", "学位论文", "博士论文目录", "thesis chapter plan"

```markdown
## Dissertation structure (draft — verify with institution)

### Front matter
- Title page (institution form)
- Abstract / 摘要 (EN + CN if required)
- Keywords
- Declaration of originality & AI use (if required)
- Acknowledgments
- Table of contents, list of figures/tables, list of abbreviations

### Body (typical STEM / social science)
| Ch. | English title | Chinese common title | Module tie-in |
|-----|---------------|----------------------|---------------|
| 1 | Introduction | 绪论 | Module 1 + 4 §4.2 |
| 2 | Literature review | 文献综述 | Module 2 |
| 3 | Methodology | 研究方法 | Module 3 |
| 4 | Results / Empirical study | 研究结果 / 实证分析 | Module 4 §4.3 |
| 5 | Discussion & conclusion | 讨论与结论 | Module 4 §4.4 |
| — | Optional: implementation, case study, or paper-by-paper compilation | 视学科而定 | User handbook |

### Back matter
- References (Module 5)
- Appendices (instruments, ethics approval, extra tables)
- Publications during degree (if required)
- CV (region-specific)
```

**Paper-by-paper (PhD):** If thesis is cumulative, map each publication to a chapter with bridging text — user lists accepted/submitted papers.

### 7.3 Proposal / 开题报告 (compact)

```markdown
## 开题报告框架

1. 选题依据（背景、意义）
2. 文献综述（研究现状、述评、空白）→ Module 2
3. 研究目标与内容
4. 拟解决的关键问题
5. 研究方法与技术路线 → Module 3
6. 可行性分析（数据、条件、风险）
7. 进度安排（甘特表文字版）
8. 预期成果与创新点
9. 参考文献（GB/T 7714）→ Module 5
```

### 7.4 Abstract package (thesis)

| Component | English thesis | Chinese 学位论文 |
|-----------|----------------|------------------|
| Abstract | 300–500 words typical | 中文摘要 硕士 ~3k 字 / 博士 ~5k 字 — **confirm handbook** |
| Structure | Background → aim → methods → results → conclusion | 研究背景、目的、方法、结果、结论 |
| Keywords | 5–8 | 3–5 中文 + 英文对照常见 |

Never invent results in abstract; pull from user summary only.

### 7.5 Defense presentation (PPT outline)

**Trigger:** "defense slides", "答辩 PPT", "thesis defense presentation", "oral defense"

Default: **12–15 slides**, 20–30 min talk (confirm program rules).

```markdown
## Defense slide outline

| Slide | Title | Content bullets (max 5/slide) |
|-------|-------|-------------------------------|
| 1 | Title | Title, name, supervisor, date |
| 2 | Outline | Roadmap |
| 3 | Background & motivation | Problem + gap (1 figure optional) |
| 4 | Research questions / hypotheses | RQ1–Rn |
| 5 | Conceptual framework | Diagram description |
| 6 | Methods overview | Design, data, analysis — no wall of text |
| 7 | Key result 1 | One figure/table + takeaway |
| 8 | Key result 2 | |
| 9 | Key result 3 | (optional) |
| 10 | Discussion | Implications + limitations (honest) |
| 11 | Contributions | 3 bullets aligned with Module 1 |
| 12 | Future work | |
| 13 | Summary | One sentence answer to RQ |
| 14 | Acknowledgments | |
| 15 | Q&A | Title slide backup |

### Speaker notes guidance
- ~1 min per slide average; Results slides may need 2 min.
- Anticipate questions: methods limitation, alternative explanations, ethics.
```

**Chinese 答辩:** Add 研究背景、技术路线、创新点、不足与展望 slides; 页数按学院要求（常见 20–25 页）。

### 7.6 Defense Q&A preparation

```markdown
## Anticipated committee questions

| Category | Example question | Suggested answer structure |
|----------|------------------|----------------------------|
| Significance | Why this topic matters? | Gap + contribution (30 sec) |
| Methods | Why this design/sample? | Trade-offs + citation |
| Results | Strongest counterargument? | Limitation + robustness check |
| Ethics | IRB / data privacy? | Factual status from user |
| Future | Next study? | 2 concrete extensions |

User fills **Suggested answer** with their data; agent supplies structure only.
```

Do not script false confidence about weak results — encourage honest limitation answers.

### 7.7 Mid-term / progress report

```markdown
## Progress report (mid-term)

1. Completed work (vs. proposal timeline)
2. Preliminary results (user-supplied)
3. Deviations from plan and reasons
4. Next 6-month plan
5. Risks and mitigation
```

### 7.8 Formatting & submission checklist (thesis)

```markdown
## Pre-submission checklist

- [ ] Template version matches graduate school year
- [ ] Heading numbering consistent (Ch1, 1.1, 1.1.1)
- [ ] All figures/tables numbered and cited in text
- [ ] References complete (Module 5 audit)
- [ ] AI use statement included if required
- [ ] Similarity check (查重) within institutional limit — user runs official system
- [ ] Supervisor sign-off pages
```

Agent does **not** advise on evading 查重 — Integrity HALT.
