## Module 4: IMRaD & Thesis Chapter Writing

### Pre-Action Checklist

```
**Writing Gate** — Confirm before drafting sections:

- [ ] Section(s) requested are named (Abstract / Intro / Methods / Results / Discussion / 摘要 / 引言 / …)
- [ ] Target venue or thesis chapter map is known (word limits, heading style)
- [ ] Output language: English (SCI) or Chinese (thesis) — per SKILL.md Hard Rule 3
- [ ] User provides: RQ, key sources, methods summary, and/or results (no invented data)
- [ ] Citation style confirmed (Module 5)

If Results requested without data → offer Results **structure template** only, marked illustrative.
```

### 4.1 Abstract (structured)

**Trigger:** "abstract", "structured abstract", "摘要"

Typical limits: 150–300 words (journal-specific; user must confirm).

```markdown
## Abstract

**Background:** [1–2 sentences — problem + gap]
**Objective:** [Primary aim / RQ]
**Methods:** [Design, n, setting, key measures, analysis — past tense]
**Results:** [Key numeric or qualitative findings — from user data only]
**Conclusions:** [Answer to RQ; no overclaim]
**Keywords:** [3–8; MeSH-style if biomedical]
```

Chinese 摘要: same logic; 结构式摘要 often **目的、方法、结果、结论**; keywords 3–5 with English parallel if required.

### 4.2 Introduction (CARS model)

```markdown
## Introduction

### 1. Territory — establish importance
[General context; cite foundational work — VERIFY]

### 2. Niche — identify gap
[Specific gap; tension or limitation in prior work]

### 3. Occupy — present this study
- Research aim / hypotheses
- Brief methods preview (1 sentence)
- Contribution bullets (2–4)
- Paper roadmap (optional, 1 sentence)
```

Avoid exhaustive literature review here — point to gap; details in Discussion comparison.

### 4.3 Results

**Rules:**

- Past tense; no interpretation (save for Discussion).
- Figure/table callouts: `(Table 1)`, `(Fig. 2)`.
- Report effect sizes, CIs, and exact p-values as user provides.
- If no data: output subsection headers + `[Insert: descriptive stats for …]` placeholders.

```markdown
## Results

### [Subheading aligned to RQ or analysis step]

[Paragraph describing finding with statistic]

**Table 1.** [Title]. [Note abbreviations.]

**Figure 1.** [Title]. [Caption standalone readable.]
```

### 4.4 Discussion

```markdown
## Discussion

### Summary of main findings
[Plain language; map to RQ/H]

### Interpretation
[Mechanism / comparison to prior studies — cited]

### Theoretical / practical implications

### Strengths
- [...]

### Limitations
- [Honest; common: sample, design, measurement, generalizability]

### Future research

### Conclusion
[1 short paragraph; no new data]
```

### 4.5 Thesis chapter mapping (Chinese 硕博)

| Chapter | Typical content | Module tie-in |
|---------|-----------------|---------------|
| Ch.1 绪论 | 背景、意义、内容、结构 | Module 1 |
| Ch.2 文献综述 | 主题综述 + 述评 | Module 2 |
| Ch.3 研究方法 | 完整方法 | Module 3 |
| Ch.4 结果/实证 | 数据分析结果 | §4.3 |
| Ch.5 讨论与结论 | 讨论 + 创新 + 展望 | §4.4 + Module 1 contributions |

Follow **school template** when user provides it; otherwise use table above.

### 4.6 Language polish (allowed)

When user supplies their draft:

- Improve clarity, cohesion, academic tone.
- Flag unsupported claims, vague antecedents, and nominalizations.
- **Do not** change technical meaning or add citations without source.
- Provide tracked-style summary: *Substantive meaning preserved; [N] clarity edits.*

### 4.7 Section word budgets (defaults — confirm with user)

| Section | Typical range (SCI) |
|---------|---------------------|
| Abstract | 150–300 |
| Introduction | 800–1200 |
| Methods | 1000–2000 |
| Results | 1000–2500 |
| Discussion | 1200–2000 |

Thesis chapters: follow institution; often 8000–15000 字 per major chapter in Chinese programs.
