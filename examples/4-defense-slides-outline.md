### Step 2: Slide outline

| 页 | 标题 | 要点 |
|----|------|------|
| 1 | 题目、答辩人、导师、单位、日期 | |
| 2 | 汇报提纲 | 背景→问题→方法→结果→创新→不足 |
| 3 | 研究背景 | 高等教育重视论证素养；写作反馈资源不足 |
| 4 | 问题提出 | 核心问题：LLM 协作反馈是否提升论证质量？ |
| 5 | 研究现状与空白 | 1 页综述（详见第2章） |
| 6 | 研究目标与内容 | 对应 RQ 与实验设计 |
| 7 | 概念框架 | LLM 反馈 × 论证要素模型（图） |
| 8 | 研究设计 | 准实验；2×2 前后测；128 人 |
| 9 | 研究对象与工具 | 本科生样本；rubric 信效度简述 |
| 10 | 实验流程 | 干预 8 周；分组说明 |
| 11 | 结果1：总体论证分数 | 前后测主效应 [用户填入 F/p/η²] |
| 12 | 结果2：分维度（主张/证据/反驳） | 各维度表或图 |
| 13 | 结果3：过程数据（可选） | 修改次数、反馈采纳率 |
| 14 | 讨论 | 与教师反馈对比的解释边界 |
| 15 | 创新点 | 用户提供的三条 |
| 16 | 研究不足 | 样本单校、短期干预、工具依赖 |
| 17 | 未来展望 | 纵向追踪、跨学科、伦理与学术诚信 |
| 18 | 结论 | 一句话回答核心问题 |
| 19 | 致谢 | |
| 20–22 | 备用 | 详细 rubric、伦理批件、附录图 |

**时间分配建议：** 背景 3 min → 方法 5 min → 结果 8 min → 讨论+创新 3 min → 结论 1 min。
